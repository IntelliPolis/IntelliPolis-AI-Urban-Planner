# IntelliPolis 개발 정리 — 2026-07-13

## 오늘의 결과

서울특별시와 6개 광역시를 대상으로 도시·구를 선택하면, 수집한 공공데이터와 외부 API를 결합해 현재 도시 현황과 AI 도시계획 대안을 비교하는 흐름을 연결했다.

## 구현 내용

### 데이터 및 백엔드

- CSV·ZIP 원본을 `backend/data/raw` 아래 분야별로 정리했다.
- 상권, 공원, 예산 등 구 단위 도시 요약 API를 구현했다.
- VWorld 배경지도 타일과 지역검색 프록시를 구현했다.
- ITS 실시간 교통속도를 조회하고 20km/h 미만 링크를 혼잡 후보로 분류했다.
- GeoTools로 연속지적도, 도시계획시설, 도시지역 SHP를 읽도록 구성했다.
- 선택 지점 반경 약 1.5km에서 500㎡ 이상 필지를 탐색한다.
- 도시계획시설과 겹치는 필지와 도시지역 밖의 필지를 개발 후보에서 제외한다.
- 법정동코드와 지적 필지를 이용해 구 경계 Polygon을 생성한다.
- Gemini 실패 시에도 규칙 기반 계획안과 설명을 반환하는 fallback을 유지했다.

### 프론트엔드

- 시·광역시 → 구·군 선택 흐름을 구현했다.
- 현재 지도와 AI 개선 지도를 나란히 비교하도록 구성했다.
- MapLibre 2D/3D 전환과 VWorld 배경지도를 연결했다.
- AI 신규 시설을 종류별 색상, 아이콘, 번호, 이름표로 구분했다.
- 시설 라벨 클릭 시 시설 종류와 배치 이유를 표시한다.
- 선택한 구 경계를 파란 면과 경계선으로 표시하고 구 전체에 화면을 맞춘다.
- VWorld에서 폐지·개편 지역을 검색하지 못해도 로컬 구 경계 중심으로 분석을 계속한다.
- ITS 평균속도, 혼잡 링크와 도로명을 대시보드에 표시한다.

## 사용 데이터 및 API

| 구분 | 활용 내용 |
| --- | --- |
| VWorld | 배경지도, 지역 좌표 검색 |
| ITS 국가교통정보센터 | 실시간 링크 속도와 혼잡 후보 |
| Gemini 3.1 Flash-Lite | 도시데이터 해석과 계획 설명 |
| 연속지적도 SHP | 필지 도형, PNU, 구 경계 생성 |
| 도시계획시설 SHP | 개발 후보 충돌 검사 |
| 국토계획/도시지역 SHP | 도시지역 내부 후보 판정 |
| 법정동코드 | 행정구역과 PNU 앞자리 연결 |
| 상권·공원·예산 CSV | 구 단위 현황 집계 |

## 현재 분석 기준

1. 사용자가 시와 구를 선택한다.
2. 구 단위 통계와 구 경계를 읽는다.
3. VWorld 좌표 또는 구 경계 중심을 분석 중심으로 정한다.
4. ITS 교통자료와 주변 공간데이터를 조회한다.
5. 500㎡ 이상이고 도시계획시설과 겹치지 않으며 도시지역 안에 있는 필지를 고른다.
6. Java 규칙 계산과 Gemini 해석으로 세 가지 계획안을 생성한다.
7. 현재 상태와 AI 계획을 지도에서 비교한다.

## 확인 결과

- 인천 동구 시험 좌표에서 도시계획시설 875개와 도시지역 도형 146개를 검사했다.
- 최종 적격 필지 388개 중 상위 20개를 후보로 반환했다.
- 백엔드 컴파일과 프론트엔드 프로덕션 빌드가 통과했다.
- 커밋 `b9400d1`을 `origin/3-기능-구현`에 푸시했다.

## 남은 과제

- 최초 구 경계 생성 시 지적 필지 병합으로 분석이 오래 걸린다. 파일 캐시와 병렬 API 호출이 필요하다.
- 인구·병원·학교 일부 값은 아직 승인 API 또는 완전한 원본 연동이 필요하다.
- AI 계획 시설은 후보 필지 중심을 활용하지만 필지 전체 형상에 맞춘 건축 배치는 아니다.
- 도시계획 대안은 의사결정 지원용 시뮬레이션이며 실제 인허가·행정 결정을 의미하지 않는다.
