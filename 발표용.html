Project Definition

우리 프로젝트는 무엇인가?

IntelliPolis의 핵심 기능을 한 문장으로 정리했습니다.

우리 프로젝트는 도시계획 담당자와 지역 주민을 위해 인구, 교통, 환경, 공공시설과 예산 데이터를 받아 Spring AI가 분야별 분석, 문제 분류, 개선안 추천과 계획안 생성 을 수행하고, 사용자에게 지도 기반 도시계획 대안과 계획별 예상 효과 를 제공하는 서비스입니다.

Service Process

도시 데이터가 계획안이 되는 과정

AI가 임의로 도시를 설계하지 않고, 입력 데이터와 규칙 기반 점수를 바탕으로 도시계획 대안을 생성합니다.

STEP 01

도시 데이터 입력

인구, 공원 비율, 병원 수, 교통 접근성, 예산 등의 데이터를 입력합니다.

STEP 02

현재 상태 계산

Java 기반 규칙 계산기가 교통, 환경, 경제, 생활 점수를 계산합니다.

STEP 03

AI 분야별 분석

교통, 환경, 경제, 생활 에이전트가 각자의 관점에서 문제를 분석합니다.

STEP 04

계획안 생성

균형형, 환경 중심형, 예산 효율형의 도시계획 대안을 생성합니다.

STEP 05

지도 시각화

제안 시설, 교통 노선과 개발 구역을 지도 위에서 비교합니다.

Multi Agent

분야별 AI 전문가 협업

하나의 Gemini API를 사용하지만, 서로 다른 역할의 시스템 프롬프트로 다양한 관점을 분석합니다.

🚦

교통 에이전트

혼잡 도로, 대중교통 접근성, 보행 환경과 이동 편의성을 분석합니다.

🌿

환경 에이전트

공원 비율, 녹지 접근성, 보행 환경과 지속 가능한 개발 방향을 분석합니다.

₩

경제 에이전트

사업 예산, 비용 대비 효과와 기존 시설 활용 가능성을 분석합니다.

🏥

생활 에이전트

병원, 학교, 문화시설과 연령별 주민의 생활 편의성을 분석합니다.
